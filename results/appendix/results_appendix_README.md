# Apêndices e Materiais Suplementares do Artigo (`results/appendix/`)

Este diretório organiza os apêndices formais e materiais suplementares derivados da revisão sistemática que acompanham o artigo científico/dissertação.

---

## 1. Conteúdo Mapeado

* **Apêndice A — Dicionário de Variáveis de Extração:** Mapeamento completo dos 26 campos padronizados do formulário de extração (`extraction/extraction_form.csv`).
* **Apêndice B — Telemetria de Desempenho e Inferência Edge:** Tabelas estendidas de testes físicos no **NVIDIA Jetson Orin Nano (8 GB VRAM)** sob limite de **15W** (`supplementary/supplementary_tables/table_s3_jetson_edge_telemetry.csv`).
* **Apêndice C — Relatórios Excluídos na Leitura em Texto Completo:** Relação fundamentada das 4 exclusões registradas no estágio de elegibilidade (`EXC_FULL_01` a `EXC_FULL_04`).

---

## 2. Relação com os Dados Primários

Os apêndices contidos nesta pasta são compilados a partir das fontes primárias do repositório (`extraction/`, `studies/` e `supplementary/`), garantindo que qualquer atualização nos dados brutos seja refletida nos anexos finais do manuscrito.
