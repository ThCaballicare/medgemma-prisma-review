# Registros Operacionais e Logs de Auditoria (`results/logs/`)

Este diretório concentra os diários de bordo e logs de auditoria que garantem a rastreabilidade determinística e a reprodutibilidade integral do processo de revisão sistemática.

---

## 1. Estrutura de Logs

```text
results/logs/
├── decision_log.md    # Registro das decisões metodológicas e estratégicas
├── screening_log.md   # Registro das etapas de seleção, triagem e arbitragem
└── search_log.md      # Registro das buscas executadas e APIs consultadas
```

---

## 2. Política de Imutabilidade

Os arquivos mantidos neste diretório funcionam como registro histórico auditável. Qualquer alteração ou nova decisão deve ser anexada com data, justificativa e identificador de decisão, preservando o histórico de alterações da revisão.
